# Session Log Template

Use this format for session logs. Written after each design or significant work session. Feeds back into skill and agent improvements.

## Template

```markdown
## <design-id>, Round <N>: <date>

### Outcome
- V score: X.XX
- P score: X.XX (or null if skipped)
- Deviations found: N/3 correctly identified
- Time spent: ~N minutes (agent time)

### What went well
- <specific things that worked as designed>

### What was hard / required manual intervention
- <specific problems encountered>
- <where the agent needed human guidance>

### Skill/agent improvements needed
- <specific wording changes, missing patterns, incorrect instructions>

### Commands or patterns discovered
- <new techniques, workarounds, shortcuts>

### Surviving mutants at end (if applicable)
- <file:line + attempted fix + why it didn't work>
```
